# Win64 internal assembler subset

The current M1 instruction selector in `win64.c` writes a private GAS-shaped
text representation. `asm_win64.c` encodes that representation into section
bytes and feeds `coff.c`; no external assembler parses or emits program
instructions. This is a transitional internal boundary. The intended next
step is for the IR code generator to emit bytes/relocations directly and remove
the textual representation.

Supported instruction spellings are limited to those generated by the M1
selector: `pushq`, `subq`, `movabsq`, `movq`, `movl`, `movslq`, `movsd`,
`addl`, `subl`, `imull`, `addq`, `subq`, `imulq`, `addsd`, `subsd`, `mulsd`,
`divsd`, `cmpl`, `cmpq`,
`cltd`, `idivl`, `ucomisd`, `sete`, `setne`, `setl`, `setle`, `setg`, `setge`,
`setb`, `setbe`, `seta`, `setae`, `setnp`, `setp`, `andb`, `orb`, `movzbl`, `leaq`,
`negq`, `xorpd`, `call`, `je`, `jmp`, `leave`, and `ret`. The parser
accepts `.text`, `.section .rdata`, `.globl`,
`.def`, `.byte`, and the current canonical `.seh_*` directives. It rejects
unknown instruction/directive forms, unsupported unwind frames, and fixed
internal table overflow with an error. It is not a general GAS implementation.

D-M1-94 to D-M1-96 add these encodings:

- `notq %reg`.
- `andq`, `orq` and `xorq`, register to register.
- `shlq %cl, %reg` (`D3 /4`) and `sarq %cl, %reg` (`D3 /7`).
- `shrq` and `shlq` with an 8-bit immediate (`C1 /5`, `C1 /4`), count 1 to 63.
- `imulq r/m64` with one operand (`F7 /5`), which leaves the 128-bit product in
  `%rdx:%rax`.

`cqto`, `idivq`, `negq`, `movabsq` (into `%rax` only), `cmpq $imm, r/m64` and
the two-operand `imulq` were already encoded. `movabsq` carries an int that does
not fit a sign-extended imm32. The generator never names another register with
it.

Unwind records are generated from actual encoded prologue offsets relative to
each function start. The current supported frame shape is the selector's
`pushq %rbp; movq %rsp, %rbp; subq $N, %rsp`, where `N` is 8..128 and divisible
by 8. The `.pdata` records point to `.xdata` through ADDR32NB relocations.

Verification on 2026-10-14: the integrated R6 driver passed all thirteen current
manual fixtures (**13/13**), with `R6_CC`
deliberately set to a nonexistent path. Earlier isolated assembler probes are
historical and do not verify the complete Orbit corpus.

Alternativa descartada: mantener GAS textual como la sintaxis pública y ampliar
un ensamblador genérico; se conserva como formato interno transitorio para que
la siguiente pieza pueda sustituirlo por emisión byte-a-byte desde el IR.
